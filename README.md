# Kantolyx 0.5.65 · GitHub Pages

A parametric browser mesh modeler, strongly inspired by **TopMod** and its approach to topological modeling.

- [English user manual](docs/MANUAL.en.md)
- [Deutsche Anleitung](docs/MANUAL.de.md)
- [Pages changelog](CHANGELOG.md)
- [Original TopMod project website](https://people.tamu.edu/~ergun/research/topology/download.html)

Open the published website, choose a starting solid, select faces and build a model through editable timeline steps. German is the default interface language; choose **English** in the header. The package includes readable source files, 40 example projects, local project save/open, OBJ export and animated timeline playback.

## Publish on GitHub Pages

1. Create a GitHub repository, for example `kantolyx`.
2. Extract this ZIP. Upload and commit the **contents** of `kantolyx-github-pages/` to the repository root. In particular, `index.html`, `app.mjs`, `kernel.mjs`, `style.css` and the hidden `.nojekyll` file must be directly at the root.
3. Open **Settings → Pages** in the repository.
4. Select **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
5. Once published, open the URL displayed by GitHub, normally `https://YOURNAME.github.io/kantolyx/`. For a repository named `YOURNAME.github.io`, the address is `https://YOURNAME.github.io/`.

No build step or npm installation is required. Relative paths support both the account root and a repository subdirectory. `.nojekyll` disables Jekyll processing. Do not open `index.html` using `file://`; JavaScript modules and workers need an HTTP(S) address. Use the published Pages URL.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Save your work

Choose **Save project** to download a `.kantolyx` file. Choose **Open project** to continue editing it. Projects are not automatically saved by the website; download important work before closing or refreshing the page. The browser remembers the interface language, not your project. **Export OBJ** exports the currently displayed mesh; OBJ does not preserve the editable timeline.

## Update the website

Replace the repository files with the contents of the next GitHub Pages package and commit. GitHub Pages publishes the new files. Existing `.kantolyx` project files can be opened again. For the documentation cleanup in 0.5.65, replace `README.md`, `CHANGELOG.md` and the files in `docs/` as well as the application files; remove any obsolete documentation you previously added to the repository. A new ZIP cannot erase earlier Git commits.

## Custom domain

An optional domain can be configured in **Settings → Pages → Custom domain**. Follow GitHub's DNS instructions and enable HTTPS when available. No domain name is preconfigured in this package.

https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
